# 돋보기 한눈에 보기

캐글·데이콘 정형 데이터 대회 참가자를 위한 로컬 분석 도구. 2026-10-17 1.0.0.

## 가져온 장점

| 가져온 것 | 어디서 | 돋보기에서 |
|---|---|---|
| train/test를 한 그림에 겹치고 타깃 관계를 같이 보기 | Sweetviz | 모든 컬럼 상세에 train/test 겹친 분포 + 타깃 관계 그래프 |
| 경고 목록을 첫 화면에 | ydata-profiling Alerts | 개요의 '주의할 점', 데이터 점검 화면 |
| 구분 분류기 AUC로 다변량 드리프트 | Deepchecks, nyaggle | 적대적 검증(원인 컬럼, 행별 test 유사도) |
| 실험마다 OOF·test 예측·제출 파일 자동 저장 | nyaggle, mljar | 기본 모델·`dotbogi.log`·앙상블 모두 `.dotbogi/runs/`에 저장 |
| CV와 LB 어긋남 경보 | kx | CV↔Public LB 상관·판정, 추세에서 벗어난 실험 표시 |
| OOF 힐클라이밍 | 캐글 상위권 기법 | 앙상블 화면 |
| 제출 기록·점수 조회 | Kaggle 공식 CLI | Kaggle 기록 가져오기 버튼 |

## 고친 불편

| 기존 도구의 불만 | 돋보기의 해결 |
|---|---|
| 범주형·다중분류 타깃 미지원 (Sweetviz, ydata) | 이진·다중·회귀 모두 타깃 관계·예측력 |
| 고유값 많은 컬럼이 타깃을 외워 관계가 부풀려짐 | 단일 피처 예측력을 다른 폴드로 잼(OOF 타깃 인코딩) |
| 80MB HTML, 열 수 제곱으로 느려짐 (ydata) | 요약만 담은 수 MB 보고서, 컬럼별 독립 계산·캐시 |
| 설치·의존성 (Python 3.12/3.13, numpy 2, pandas 3) | pandas·numpy·scipy·scikit-learn·pyarrow만, pandas 2·3 모두 |
| 한국어 없음, 한글 깨짐 | 한국어 화면, 한글 컬럼명, cp949 자동 판별 |
| Deepchecks 1만 행 표본, 2024년 이후 정지 | 적대적 검증 train·test 각 10만 행, 컬럼 빼고 다시 |
| 실험 추적기에 LB 개념 없음, 시트 수동 기록 | CV·Public·Private 대장, 스크립트 한 줄 기록, 바로 고치기 |
| CV-LB 차이를 판단할 기준이 없음 | OOF로 Public LB 흔들림 크기와 두 실험 승률 계산 |
| 최종 제출 고르기, 데이콘 자동 변경 함정 | 최종 2개 추천과 이유, 플랫폼별 주의 안내 |
| 제출 형식 실수 | 제출 검사 + 의미를 바꾸지 않는 자동 수정 |
| 힐클라이밍 과적합 (음수 가중치, 같은 폴드 조기 종료) | 양수 가중치만, 폴드 교차 정직한 점수, 학습 폴드 안쪽으로 조기 종료 |
| 검증 방법 추천이 없음 | 시간·그룹 구조 감지 → 추천 + folds.csv + 코드 조각 |

## 새로 더한 것

- 검증 설계 도우미 (추천 이유, 폴드 파일, 폴드별 요약)
- Public LB 흔들림 시뮬레이션
- 정직한 앙상블 점수
- 사람용 화면과 스크립트·에이전트용 명령줄(`check`, `sub-check` 종료 코드)이 같은 기록을 공유
- 노트북 안에 바로 띄우는 보고서 (`dotbogi.report`)

## 일부러 뺀 것

이미지·텍스트·음성 대회 전용 분석, AutoML·하이퍼파라미터 튜닝, 클라우드 동기화, 데이콘 자동 제출, 영어 화면, 피처 자동 생성.

## 검증

- 자동 테스트 55개: 심어 둔 문제 데이터, 실제 대회 데이터 구조, 독립 검수에서 나온 결함 21건의 재발 방지.
- 화면 자동 점검: 실제 브라우저(Edge)로 모든 화면·창·보고서·서버 꺼짐을 눌러 보고 콘솔 오류 0.
- 환경: Python 3.12 + pandas 3 + LightGBM, Python 3.13 + pandas 2.2 + LightGBM 없음, 설치 파일(wheel)로 설치.
- 성능: 70만 행 열기+컬럼 분석 약 9초, 300만 행 약 7초, 다시 열기 1초 이내.

## 알려진 한계

- Kaggle 제출 기록 가져오기는 가짜 Kaggle CLI로만 확인했습니다. 실제 계정·토큰으로는 시험하지 않았습니다.
- 타깃이 여러 개인 대회는 기본 모델이 타깃마다 학습해 제출 파일을 채우지만, OOF·앙상블·LB 흔들림은 첫 타깃 기준입니다.
- 이미지·텍스트·음성 대회 전용 분석은 하지 않습니다(문장 컬럼은 글자 수로만 봅니다).
- 화면은 한국어만 있습니다.
